# Bên Khung Cửa Nhỏ — Little Sill

A cozy single-page web game: a window sill, a sleeping cat, plants to grow and small neighbours who leave notes.

- Play: open `index.html` (self-contained, all art embedded).
- Art sources: `src/` (drawings), cutouts in `assets/`.
- Build: `work/cut_*.py` → `work/build_scene.py` → `work/build_room3.py` → `work/build_html.py .` (writes `index.html` from `src/index.template.html`).
